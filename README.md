# Double Cover

A game demo (or two) about how unit quaternions double cover the space of 3D rotations. These demos show what can be done when you don't assign both quaternions q and -q to have the same effect.

* [A two sided version,](https://1p6.github.io/Double-Cover/two_sides/double-cover.html) where quaternions are somewhat arbitrarily placed into one of two sides.
* A 4D version (WIP), where each quaternion is treated as the 4D unit vector that it is.
